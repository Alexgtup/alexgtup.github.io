# Пакет внешних публикаций Alexuys

Цель: усиливать внешний footprint портфолио естественными индексируемыми материалами, а не копипастом и link-spam.

## 1. Главный технический кейс - индексация портфолио

Базовый фактический материал:
- `EXTERNAL_INDEXING_CASE_STUDY.md`
- тема: `Как я диагностировал индексацию портфолио из 74 URL и почему не стал бесконечно переписывать SEO-тексты`

Контрольная точка материала:
- 74 URL в search sitemap
- 9/74 indexed
- 65 URL unknown to Google
- первые коммерческие seed-pages успешно crawled/indexed
- IndexNow и Yandex endpoint возвращают HTTP 200
- внутренний link graph проверен от уже indexed страниц
- performance ещё не доказывает рост трафика/топ

Перед публикацией обновлять только свежие фактические цифры. Не дорисовывать успехи.

## 5. Правило публикаций

- не копировать один текст на несколько доменов;
- не публиковать несколько материалов в один день;
- для каждой площадки менять структуру, заголовок и вступление;
- ссылаться на конкретный кейс только когда он реально дополняет материал;
- не использовать link-spam, каталоги и массовые гостевые посты;
- не обещать рост трафика, топ или заявки до появления данных;
- перед публикацией обновлять indexed/impressions/clicks и даты crawl;
- KPI после размещения: новый crawl -> indexed verdict -> impressions -> clicks -> query/page data.
