БЕЗ ВХОДА · LOCAL-FIRST

Полезные web-инструменты без регистрации.

Шесть узких утилит для разработки, SEO, автоматизации и маркетинга. JSON, JWT, robots.txt, sitemap и параметры ссылок обрабатываются прямо в браузере.

01 / CRON BUILDER

Собрать cron-выражение и не перепутать поля.

Бесплатный cron builder: собрать выражение минута, час, день месяца, месяц и день недели, использовать готовые пресеты и скопировать результат.

02 / JSON FORMATTER

Проверить и отформатировать JSON онлайн.

Бесплатный JSON formatter и validator: проверить синтаксис JSON, красиво отформатировать, минифицировать и скопировать. Всё работает локально в браузере.

03 / JWT DECODER

Посмотреть JWT без отправки токена на чужой сервер.

Бесплатный JWT decoder: декодировать header и payload JSON Web Token в браузере. Токен не отправляется на сервер. Подпись не проверяется.

04 / ROBOTS VALIDATOR

Проверить robots.txt онлайн.

Бесплатная проверка robots.txt в браузере: директивы User-agent, Disallow, Allow, Sitemap, блокировка корня и базовые ошибки структуры.

05 / SITEMAP VALIDATOR

Проверить sitemap.xml онлайн.

Sitemap Validator: проверка sitemap.xml онлайн — XML, loc, дубли, urlset/sitemapindex. Базовая XML-проверка Google News sitemap без валидации news:* тегов.

Подробнее ↗
06 / UTM BUILDER

Собрать UTM-ссылку без ручного кодирования.

Бесплатный UTM builder: добавить utm_source, utm_medium, utm_campaign, utm_term и utm_content к URL. Сборка ссылки полностью в браузере.
