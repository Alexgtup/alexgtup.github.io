# Stage 11 — Performance / Core Web Vitals

## Что изменено

- Три тяжёлые карточки «Фин Планера» перекодированы в WebP с высоким визуальным качеством без изменения размеров 1122×1402.
- Для карточек и оригинальных скриншотов добавлены responsive-варианты 720/800 px и `srcset`/`sizes`.
- Все изображения кейсов имеют явные `width`/`height`, что снижает риск CLS.
- Изображения ниже первого экрана используют `loading="lazy"`, `decoding="async"` и низкий fetch priority.
- Первый экран image-led кейсов использует responsive preload + `fetchpriority="high"`.
- Scroll-обработчики переведены на `requestAnimationFrame`, чтобы не выполнять лишнюю работу на каждом событии прокрутки.
- Декоративные pointer-эффекты главной теперь запускаются только на устройствах с точным указателем и шириной от 900 px.
- На мобильных отключён дорогой `backdrop-filter` в sticky header/cookie UI.
- В GitHub Pages workflow добавлен performance budget: крупные full-size WebP больше 400 KB и изображения без размеров блокируют деплой.

## Вес изображений

До оптимизации case-assets: ~4.1 MB.
После оптимизации с responsive-вариантами: ~1.7 MB.
