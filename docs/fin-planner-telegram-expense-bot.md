# Fin Planner: Telegram-бот для учёта расходов и доходов

Fin Planner - кейс Telegram-бота для личного бюджета. Пользователь фиксирует доходы и расходы внутри Telegram, распределяет операции по категориям и получает общую картину бюджета без отдельного интерфейса для ежедневного ввода данных.

Полный кейс с интерфейсами: https://alexgtup.github.io/cases/fin-planner/

Разработка Telegram-ботов: https://alexgtup.github.io/telegram-bots/

## Пользовательский сценарий

Основной сценарий начинается с регулярного ввода финансовых операций. Для такого продукта важно не только сохранить сумму, но и связать запись с типом операции, категорией и текущим состоянием бюджета.

В кейсе используются сценарии учёта доходов и расходов, просмотра баланса, регулярных платежей, отчётов, целей и финансового анализа. Telegram выступает привычной точкой взаимодействия, а логика продукта остаётся на стороне backend и данных.

## Что важно при разработке похожего бота

Функции зависят от задачи. Для простого личного учёта достаточно операций, категорий и отчёта за период. Более развитый продукт может включать несколько счетов и валют, совместный бюджет, экспорт, Google Sheets, лимиты, напоминания или Telegram Mini App для сложных экранов.

Перед разработкой полезно определить один законченный цикл: как пользователь добавляет операцию, как исправляет ошибку и какой итоговый отчёт получает. Это помогает не превращать бота в набор несвязанных команд.
