## Habr - использовать только по правилам площадки

Свежие правила Habr 2026 прямо запрещают несанкционированную рекламу и самопиар. Если цель публикации - продвигать проект, услугу или персональный бренд, такой материал допустим только в корпоративном блоге или однократно в хабе `Я пиарюсь`.

Дополнительный практический барьер: для публикации в `Я пиарюсь` требуется карма +30.

Поэтому Habr НЕ считать гарантированным бесплатным backlink-каналом.

Варианты:
1. Если у аккаунта есть доступ к `Я пиарюсь` - адаптировать технический материал туда и оставить одну уместную ссылку.
2. Если доступа нет - публиковать только самостоятельный инженерный материал без рекламной цели и без ожидания SEO-backlink эффекта.
3. Не маскировать рекламную статью под обучающий материал.

Старый файл `03-habr-telegram-product.md` остаётся архивным исходником, но больше не является главным внешним приоритетом.

## vc.ru - не считать бесплатным SEO-источником

По текущей справке vc.ru публикации коммерческих аккаунтов без Pro скрываются из внутренней дистрибуции и не индексируются поисковыми системами.

Поэтому vc.ru можно использовать как авторскую площадку только если публикация действительно самостоятельная и аккаунт не попадает под коммерческие ограничения. Покупать Pro ради одной ссылки в текущей стратегии не планируется.

Старые `01-vc-fin-planner.md` и `02-vc-crm.md` сохраняются как черновики, но не являются P0.

## DEV Community и похожие tech-площадки

DEV разрешает публикацию самостоятельных технических материалов, но их Content Policy запрещает контент, созданный прежде всего ради promotion/backlinks. Профильные пользовательские ссылки дополнительно маркируются как UGC.

Следовательно:
- материал должен быть полезен сам по себе
- не использовать формат `короткий текст -> читать дальше на моём сайте`
- не перегружать ссылками
- одну контекстную ссылку оставлять только если она реально помогает читателю
- не считать такую публикацию гарантированным SEO-backlink

DEV полезен как дополнительный публичный author/entity footprint и международная дистрибуция, особенно для английской версии портфолио.

## Что НЕ делать

- не покупать сотни дешёвых ссылок
- не делать каталожный link-spam
- не создавать новые keyword-клоны коммерческих страниц
- не копировать один текст дословно на несколько площадок
- не добавлять выдуманные клиенты, цифры роста, сроки или позиции
- не писать `вышел в топ`, пока GSC этого не подтверждает
- не использовать `referringUrls` из URL Inspection как KPI
- не переписывать Telegram / CRM / n8n страницы без query/page данных

## Метрики прогресса

Основная последовательность:

1. новый crawl date
2. indexed verdict
3. impressions по внутренним URL
4. query -> page relationships
5. clicks
6. переходы в Telegram / lead events
7. заявки

Для внешнего материала дополнительно:
- публичная страница открывается без авторизации
- материал индексируем или хотя бы доступен crawler
- ссылка не нарушает правила площадки
- после размещения целевой URL получает новый crawl или начинает собирать impressions
