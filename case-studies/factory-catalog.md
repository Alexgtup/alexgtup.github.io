# B2B-каталог завода — продукция, заявки и внутренний учёт

Веб-каталог для производственной компании — это не только карточки продукции. В проекте важно связать внешний интерфейс для клиента с заявками и внутренним рабочим контуром компании.

Такой подход позволяет использовать сайт как реальный канал продаж: посетитель находит продукт, формирует запрос, а данные продолжают движение уже внутри компании без повторного ручного ввода.
