# Stage 15 — Full Visual QA

Дата: 2026-09-06

## Что проверено

- 30 пользовательских маршрутов: 29 URL из sitemap + 404.
- Первичный геометрический аудит выполнялся на 17 ширинах от 320 до 1920 px и использовался для поиска проблемных диапазонов.
- После исправлений выполнен повторный Chromium layout-run для всех 30 маршрутов на 320, 390, 768, 1024, 1440 и 1920 px: 180 финальных проверок.
- На финальном прогоне: 0 document overflow и 0 выходов ключевых layout-контейнеров за viewport.
- Дополнительно сделаны полноэкранные визуальные рендеры ключевых страниц на mobile/desktop и точечные проверки проблемных компонентов.

## Исправлено

- Главная: мобильная композиция CRM/телефон/чат больше не торчит за viewport.
- `/app-development/`: устранён мобильный горизонтальный overflow и нестабильный перенос длинного H1.
- `/cases/`: glow-декор ограничен границами карточек и больше не создаёт обрезанные артефакты.
- `/guides/n8n-vs-make/`, `/guides/telegram-bot-cost/`, `/guides/custom-crm-or-ready/`: таблицы на телефонах превращаются в читаемые карточки вместо выхода за экран.
- `/cases/factory-catalog/`: перестроена промежуточная tablet-сетка карточек товаров, чтобы подписи не сжимались в узкую колонку.
- Добавлены отдельные mobile/tablet правила для длинных заголовков, CTA, микро-типографики и safe-area.
- Улучшены размеры основных интерактивных элементов на touch-устройствах.
- IndexNow workflow теперь при изменении глобальных CSS/JS отправляет все sitemap URL, поскольку изменение затрагивает весь сайт.

## Финальная техническая проверка

- sitemap: 29 URL, все существуют в чистой сборке.
- 0 дублирующихся title.
- canonical соответствует маршруту.
- по одному H1 на индексируемой странице.
- JSON-LD парсится.
- внутренние ссылки не ведут на отсутствующие страницы.
- локальные asset-ссылки существуют.
- изображения имеют alt, width и height.
- мобильные таблицы имеют `data-label` для каждой ячейки.
- JavaScript проходит `node --check`.
- CSS-блоки сбалансированы.
- максимальный WebP остаётся ниже performance budget 400 KB.
- чистая публикуемая сборка около 2.28 MB.

## Примечание

Финальный повторный браузерный прогон выполнен на шести опорных/граничных ширинах. Остальные промежуточные ширины использовались в первичном поиске дефектов; исправления сделаны диапазонными media-query, а не только под один конкретный телефон.
